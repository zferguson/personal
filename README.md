# Personal Projects Repository

Welcome to my personal projects repository! This repo contains a variety of scripts, notebooks, and applications across Python and R, as well as notes and data for experimentation and learning.

## Structure

```
README.md                # Project overview and structure
python/                  # Python code, scripts, notebooks, and apps
    apps/                # Python applications (e.g., Streamlit apps)
    notebooks/           # Jupyter notebooks
    scripts/             # Standalone Python scripts
    utils/               # Utility modules and helpers
r/                       # R scripts and notebooks
    notebooks/           # RMarkdown notebooks
    scripts/             # R scripts
notes/                   # Notes, ideas, and research
    general/             # General notes and changelogs
    ideas/               # Project and research ideas
    research/            # Research notes
    ...
data/                    # Data files
    raw/                 # Raw data (e.g., CSVs)
    processed/           # Processed/cleaned data
```

## Getting Started

1. Clone the repository:
   ```sh
   git clone https://github.com/<your-username>/personal.git
   cd personal
   ```
2. (Optional) Set up a Python virtual environment:
   ```sh
   python3 -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt
   ```
3. Explore the `python/` and `r/` directories for scripts and notebooks.

## Notes
