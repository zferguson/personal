What Makes a Well-Formed Story
Field Required Guidance
Title Yes Verb-led, specific. "Draft KRI definitions for operational risk" — not "KRI work." Someone else should know what done looks like from the title alone.
Assignee Yes One person only. If it needs two people, split it into two Stories.
Parent Milestone Yes Every Story must belong to a Milestone. Unlinked Stories won't appear in the Plan view.
Start Date Yes When you expect to begin — not when it was created.
Due Date Yes Target completion. If unknown, use your best estimate and add a comment flagging the uncertainty.
Description Optional Use for context, links, or acceptance criteria. Keep updates in Comments, not the Description.
